# Oxy Server Manager · demo y servicio

## Problema que resuelve

Organizar servidores de Minecraft en Windows sin mezclar instancias, respaldos, mods ni configuraciones. El administrador reúne acciones y diagnóstico en una aplicación local.

## Demostración

![Navegación por los paneles del administrador](oxy-server-manager-demo.gif)

Esta demostración se generó con la interfaz real y una instancia ficticia, en una carpeta aislada. El servidor y Playit permanecieron apagados. Muestra navegación; no es una medición de rendimiento ni una prueba de conexión a Internet.

## Encargo que puedo preparar

1. Acordar versión de Minecraft, modpack, equipo y resultado esperado.
2. Preparar una instancia independiente y revisar compatibilidad.
3. Configurar memoria y Java para el equipo disponible.
4. Comprobar arranque y conexión en el entorno acordado.
5. Entregar instrucciones para iniciar, detener y respaldar.

El hosting, hardware, cuentas, plugins de pago y administración permanente se cotizan o contratan por separado. No se promete una cantidad de jugadores o FPS sin evaluar el equipo y el modpack. Se acuerda por escrito el alcance antes del trabajo.

## Tecnología

Python, PySide6, procesos locales, configuración persistente, gestión de archivos y diagnóstico del servidor. Proyecto personal desarrollado con asistencia de IA.
